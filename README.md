# 口语阶梯

英语口语练习工具：选一集故事，生成提示词贴到 ChatGPT 里用语音练，练完把复习卡存下来，下次 AI 会先考你。

单个网页，可以在电脑浏览器里用，也可以在 iPhone 上添加到主屏幕，当成 App 用，没有网络也能打开。

## 在 iPhone 上添加到主屏幕

1. 用 **Safari** 打开网址（其他浏览器不行）。
2. 点底部的「分享」按钮（方框加向上箭头）。
3. 在列表里找到「添加到主屏幕」，点「添加」。
4. 以后从主屏幕的「口语阶梯」图标打开。

第一次打开要联网。打开过一次以后，没网也能用。

## 复习卡存在哪里，怎么在手机和电脑之间同步

复习卡和练习设置只存在当前这台设备的浏览器里，不会上传。iPhone 主屏幕上的 App 和 Safari 里打开的网页，存的是两份。

想把一台设备上的复习卡搬到另一台：

1. 在有卡的设备上，打开「复习本」，点「导出」，再点「复制」。
2. 通过微信文件传输助手、备忘录、邮件等，把这段文字发到另一台设备。
3. 在另一台设备上，打开「复习本」，点「导入」，粘贴，再点「导入」。

导入时按每组卡的编号合并：已经有的不会重复，原有的卡也不会被删掉。练习设置（级别、集数等）会换成导入的那份。

清除 Safari 网站数据或删掉主屏幕图标，存的卡也会一起清掉。建议隔一段时间导出一次，自己留个备份。

## 以后改内容

所有内容都在 `index.html` 里：

| 想改的东西 | 在 `index.html` 里找 |
| --- | --- |
| 11 个级别（说明、语法单元、句式、话题） | `const LEVELS` |
| 33 集故事 | `const EPISODES` |
| 每级复习的场景 | `const REVIEWS` |
| 重演时的变化 | `const TWISTS` |
| 自由聊的话题 | `const TOPICS` |
| 提示词末尾的 Murphy 单元表 | `const UNIT_MAP` |
| 提示词的拼法 | `buildPrompt` 及上面的 `storyNew`、`storyReplay`、`storyReview`、`freePrompt`、`talkRules`、`tail` |
| 页面上的文字和样式 | `<body>` 里的 HTML、`<head>` 里的 `<style>` |

**改完之后，一定要把 `sw.js` 第一行附近的 `VERSION` 改大一点**（比如 `v1` 改成 `v2`）。这个页面会被缓存起来供离线使用，不改版本号的话，手机上会一直显示旧内容。

推送到 GitHub 以后，等一两分钟让 Pages 更新。手机上把 App 完全关掉再打开，一般要这样打开两次才会看到新内容。

## 文件

- `index.html`：整个页面，包括数据、逻辑和样式
- `manifest.webmanifest`：添加到主屏幕时用的名称、图标和颜色
- `sw.js`：离线缓存
- `icons/`：App 图标

本地预览：

```bash
python3 -m http.server 8000
```

然后打开 <http://localhost:8000>。
